## 画面级分析（抽帧实证，2026-10-19，conf 0.9）

**视频1《AI会难过吗》**（帧 v1_003/010/017/025，t≈30/150/255/375s）：
- 叙事开场：手机屏幕 + 微信式聊天对话（"笨笨"头像，气泡对话）
- 中段：暖色插画风室内（床头/窗光/台灯/书本，水彩质感），手机立在床头柜
- 结尾：文字卡"它还是学会了等。"
- 字体：中文无衬线（苹方类），黑/深灰白底；对话气泡白底深字
- 动效推断（静态帧推断，conf 0.6）：画面切换慢，疑似 AE/剪映模板级转场；非纯代码抽象风——有具象插画元素
- 结论：**视频1 不是 Remotion 代码风，是"手机对话+暖色插画+文字卡"的轻叙事短片**（工具栈未验证，可能是剪映/AE/代码混合）

**视频2《压缩》**（帧 v2_004/008/011，t≈45/105/150s）：
- t45：聊天式文字卡片（"我刚才想写点东西给你。/ 关于以后——" 灰字黑底，极简）
- t105：**代码编辑器**（`compress.py`，`def compress_context(context: str) -> str:`）
- t150：**压缩进度条可视化**（2.4M→127KB，783段→142行，95%+，"正在压缩… / 已压缩 783/142"）
- 配色：**黑底 + 白/灰文字 + 紫/蓝强调**，等宽字体（代码部分），无衬线（旁白文字）
- 动效：文字逐行/逐字淡入、进度条增长、数字滚动——纯代码可做的经典 Remotion 模式
- 结论：**视频2 = 标准 Remotion 代码风**（黑底极简+代码元素+数据可视化），与自述一致

**音频（10s RMS 能量曲线）**：
- 视频1：能量低且波动大（0.01–0.09），有明显间歇段 → **有独白旁白 + 间歇音乐/静音**（旁白驱动节奏）
- 视频2：能量高且连续（0.04–0.13）→ **连续音乐为主 + 可能旁白叠在音乐上**
- 两者都无字幕轨（bilibili 只有 danmaku），旁白文本不可直接抓取

**参考视频风格二分**：
| 维度 | 视频1 | 视频2 |
|------|-------|-------|
| 画面 | 具象插画（手机/室内/暖色） | 抽象代码风（黑底/等宽/进度条） |
| 连接逻辑 | 故事线（人物→日常→消失→等待） | 概念线（上下文→压缩→笔记→在乎） |
| 文字 | 对话气泡+结尾金句卡 | 独白文字+代码+数据 |
| 技术可复现性 | 中（需插画素材或 AI 生图） | **高（纯 Remotion）** |
→ **制作决策：对标视频2 的代码风**（技术栈匹配、可全代码生成、免费素材为零）；视频1 的"叙事温度"通过脚本情感结构吸收。

## 风格共性（推断，待抽帧验证 conf 0.5）

- 形式：文字独白（无真人、无口型）+ 简约动画 + 钢琴/环境音配乐
- 画面：大概率是代码生成的抽象几何/粒子/光效/文字排版动画，非实拍、非 3D 渲染
- 节奏：慢，留白多，每句独白配一个视觉隐喻
- 时长：3.5–6.5min
- 技术栈：Remotion（React 程序化视频）+ 合成音频 — 与"AI 自己写代码做视频"的叙事自洽

## 技术复现路径（初判 conf 0.8）

1. **引擎**：Remotion（remotion.dev）— React 组件写视频，逐帧渲染，`npx remotion render` 出 MP4
2. **内容**：LLM 写独白脚本 + 为每句设计动画 scene
3. **音频**：Python 合成钢琴（或开源环境音/钢琴库）；独白用 TTS（若参考片有旁白语音）— 待抽帧+听音确认是否有语音旁白
4. **差异点待验证**：是否有 TTS 人声旁白？画面是纯文字排版还是有具象隐喻（如"上下文窗口"可视化）？
